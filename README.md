# DSP-Based Digital Equalization System (ZF/MMSE)

## The Problem
Thermodynamic sensors suffer from physical thermal lag and signal distortion, leading to inaccurate real-time measurements and delayed system responses.

## The Solution
Developed a digital equalization system (in collaboration with Elbit Systems). Implemented Zero-Forcing (ZF) and Minimum Mean Square Error (MMSE) algorithms in Python to compensate for thermal delay, reconstruct the original signal, and optimize the Signal-to-Noise Ratio (SNR).

## Tech Stack
* Python (NumPy, SciPy, Matplotlib)
* Digital Signal Processing (DSP)
